# content.json 格式规范 (模式B: 无参考版)

由 worksheet.json 复制而来, 逐槽位填写 `cn` 字段。这是**译文的唯一载体**,
翻译质量全部体现在这个文件里, 构建脚本不做任何翻译。

## 整体结构

```json
{
  "src": "paper.pdf",
  "slots": [
    {
      "id": "p1-c0-2",              // 必须与 worksheet 一致, 勿改
      "page": 1, "col": 0,          // 只读
      "cn": "视觉语言跟踪旨在利用初始帧中提供的模板块和语言描述……",  // ← 填这里
      "size": 10.0,                 // 可选, 覆盖字号
      "gap": 118.0                  // 可选, 覆盖可用高度
    }
  ],
  "overlays": [                     // 可选: 图表内文字汉化
    {"page": 6, "find": "Method", "cn": "方法"},
    {"page": 1, "find": "Action", "cn": "动作", "size": 5.0}
  ]
}
```

## 标记语法 (cn 字段内)

| 标记 | 效果 | 例 |
|---|---|---|
| `**…**` | 粗体 (思源宋体 Bold) | `**鲁棒的跟踪**` |
| `^{…}` | 上标 (0.72×, 上移 0.33em) | `冯晓坤^{1,2*}` |
| `_{…}` | 下标 (0.72×, 下移 0.22em) | `f_{X}` |
| `$…$` | 数学段 (字母走 Computer Modern 斜体) | `$f_{X}^{t} ∈ ℝ^{N×D}$` |

- 数学段内 `_` `^` 照常工作; `∈ ⊙ ℝ ⊕` 直接写 Unicode, 缺字形自动回退到符号字体。
- 没有斜体标记——中文排版不用斜体; 西文书名/强调保持正体即可。
- 引用编号 `[9]`、数字、单位原样写。
- 禁止出现英文句子残留 (专有名词/基准名如 MGIT、LaSOT 保留是正常的)。

## 模式B 新增可选字段 (换新论文时按需使用)

| 字段 | 作用 |
|---|---|
| `math_exclude_stems: ["CMR","CMBX"]` | **正文本身就是 CM 家族时必须填** (Springer/LaTeX 正文 CMR10), 否则每个正文行都被判成数学行 |
| `extra_zones: [{"page":7,"x0":..,"y0":..,"x1":..,"y1":..}]` | 自动检测漏掉的保留区 (只有横线的书板表格、拼图式插图、曲线型结果图)。用 `scripts/_mkzones` 式的"图注锚定"脚本生成 |
| `zone_trim` | 自动区域裁掉一部分 (救回被区域吞掉的图注) |
| `cite_color: "#0000ff"` | hyperref 引用色。配合 cn 里的 `[[...]]` 标记逐字染色 |
| `keep_ranges` | 参考文献页 / 整页结果图不抹白 (支持 x0/x1) |
| `linkify: {"apply": true}` | 左半重建原页链接 + 右半 `[n]`/URL 跳转 |
| 槽位 `gap` 覆盖 | 原页行距过紧 (如作者行 2 行塞进 22pt) 时手工给足空间, 避免引擎压到 1.24 硬塞 |
| 槽位 `size` 覆盖 | 同上, 需要更小字号时 |

## 标记语法补充

| 标记 | 效果 |
|---|---|
| `[[…]]` | 引用/链接蓝 (色值由 `cite_color` 给)。**必须成对**, 未闭合会原样画出方括号 |
| 段内 `
` | 另起一段 (项目符号列表就靠它: 每个 `•` 前加 `
`, 后续段自动缩进 10pt = 悬挂缩进) |

## 交付前的机器自检 (本次新增)

1. 标记配对: `[[ ]]`、`**`、`$`、`^{}`、`_{}` 计数 + 反斜杠扫描 (残留 LaTeX 命令)
2. 构建日志: `[警告]` 必须为 0; `[缩排]`/`[顺接]` 逐条确认可接受; `[碰撞检测] 通过`
3. 保留区覆盖审计: 逐页比对"源页文字行 - 保留行 - 抹白行", 确认保留的英文行都落在图/表/公式上
4. 中文×保留英文重叠 = 0 (克隆正文虽仍在 PDF 内部, 但被抹白覆盖, 不算冲突)
5. 无缺字形 (逐字符过字体链)
6. 轴标题/图内标签是否还有英文残留 (旋转标签最容易漏)
7. 逐页渲染 → 视觉审核 (judge agent), 每个 fail 都要定位到具体坐标再修

## 翻译质量要求 (验收时逐条对)

1. **覆盖**: 每个 slot 都必须填。填不出的(纯公式槽/参考文献头)也要填合理的中文或占位说明。
2. **忠实**: 不增译不漏译; 长句允许拆分, 但语义单元一个不能丢。
3. **术语一致**: 动笔前先通读全文建术语表 (如 target word→目标词, context word→上下文词,
   template patch→模板块), 全文严格统一; 基准/方法名 (MGIT, LaSOT, ATCTrack) 不译。
4. **人名**: 外国人名不臆造汉字, 用学界通行译名或保留英文。
5. **粗体对齐**: 英文加粗的术语词组, 中文对应词组加粗。
6. **图表槽位**: 图注/表注槽位翻译正文; 图表**内部**文字用 overlays 汉化
   (只挑英文标签行, 一个 find 唯一命中), 数字和方法名不要动。
7. **脚注**: 脚注槽位照翻 (如 "*同等贡献 †通讯作者")。

## 填写工作流

1. 打开 worksheet.json, 对照原 PDF 逐段读 en_text (只有前 200 字符, 需要时回原 PDF)。
2. 先建术语表 (写在本文件或单独 glossary), 再动笔。
3. 按页分批填 cn, 每页填完自查一遍覆盖和标记语法 (JSON 转义: 引号 `\"`, 反斜杠 `\\`)。
4. 全部填完跑 build_solo.py, 再跑 audit.py 自洽校验 + 逐页目检。
