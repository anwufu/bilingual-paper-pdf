# 坑清单 (pitfalls) — 每一条都是实战踩出来的, 动手前通读一遍

## 字体坑 (最致命, 版面质感的一半在字体)

1. **MuPDF 画 Adobe CFF 轮廓的 OTF 会画出错字形** (Story 引擎和 insert_text 都中招,
   报 `Reserved charstring byte` / `Index bounds`, 渲染出来全是无关汉字)。
   ⇒ 中文一律用 **Noto Serif SC 的 TrueType 实例** (setup_fonts.py 从可变字体实例化)。
   CMU-Italic.otf 是 CFF 但实测画字正常——**任何新字体必须先渲染字体测试卡肉眼确认**,
   `fitz.Font.has_glyph` 返回 True 不代表画出来是对的。

2. **PDF 内嵌子集字体没有 cmap, 不能提取复用**。从参考版提取的思源宋体子集
   `has_glyph('跟')==0`——CID 键控, 只能按字形号取字。⇒ 只能下载完整字体,
   不要试图复用参考版内嵌字体。

3. **`doc.subset_fonts()` 会损坏 CFF 字体**。交付文件过大时不要用 PyMuPDF 子集化,
   要压体积用 fontTools 对用到的码点做子集 (或接受 40MB)。

4. **参考版用的字体名就是配料表**: span 的 `font` 字段直接告诉你它用什么字体
   (如 SourceHanSerifCN-Regular/LXGWWenKaiGB/NotoSerif-Italic/NimbusRomNo9L/CMMI/MSBM)。
   字体映射表见 build_from_plan.py 的 `map_font`, 换参考版时核对一下。

## 字符坑

5. **提取文本里的 `\x01` 几乎总是空格** (中英文之间的空格, ToUnicode 缺失的子集字体)。
   验证方法: 看它的左右邻居 span——边界全是 `中文[]英文` 即空格。`\x03` 常见是 `/`。
   不要想当然当成连字符去修。

6. **MSBM10 字体的 'R' 实为黑板体 ℝ** (还有 N→ℕ, Z→ℤ)——PDF 映射表把它标成了 ASCII。
   不修的话版面上会出现普通 R, 审核时才看得见。build_from_plan.py 已特判。

7. **缺字形逐字符回退**: Noto Serif SC 缺 `∈ ⊙` 等数学符号 (Times 也缺)。
   draw_spans 里逐字符检查 `has_glyph`, 缺了就路由到 SYM (Segoe UI Symbol)。
   新字体组合务必跑全量字形覆盖审计。

8. **数学记号的字体身份**: LaTeX 论文行内数学是 CMMI (斜体字母 f/h/x/V/Norm...)、
   CMSY (∈ ⊙ ×)、MSBM (黑板体)。把它们排成正体是"内容级差异", 审核必抓。
   CMMI → CMU Serif Italic (CTAN, Computer Modern 同形)。

9. **碎片 span**: 高度 < 0.5×字号 的 span 是渲染切片不是真字符, 丢弃。

## 差分分类坑

10. **参考版"自己排的字"用字符占比判定** (CJK 占比 > 0.25), 不要用字体名白名单
    (字体名是参考版特定的, 换一篇就对不上)。克隆来的英文行 CJK 占比 ≈ 0。

11. **抹白矩形 padding**: 横向 1.0pt、纵向 0.7pt。padding 过大会吃掉相邻公式的
    上下伸部; 过小会残留英文反锯齿边。

12. **印章/页边注**: 竖排 arXiv/版权章在 x < 7.5% 页宽处, 是文字行, 分类时必须
    先排除, 否则会被抹白 (左页有右页没有, 立刻穿帮)。

13. **"同位置不同文字"的行** (图注、表格表头) 归入抹白, 内容由参考版中文行承担——
    anomaly 报告里全是这种属正常; 若 anomaly 里出现表格数字, 说明差分有 bug。

## 模式B (无参考版) 坑

14. **独立公式行的识别**: CM 数学字体主导 + 行宽 < 0.72 栏宽 + 列内近居中。
    三个条件缺一不可, 否则会把含行内公式的正文行误保留, 或把短正文行误保留。
    生成 worksheet 后必须逐页核对保留分类。

14b. **公式碎片靠"邻域生长"吸收**: 矩阵行/分段分支/上下标行/编号 `(2)` 都是与公式主体
    垂直相邻 (<=6pt) 的独立行。生长规则: 相邻且 (CM 主导 或 非顶格且不满宽) -> 一并保留。
    注意 AAAI 的数学粗体是 CMBX10 (CM 前缀 ✓), 但公式下标常用**正文字体的小字号**排
    (如 'concat'/'adj' 用 Nimbus 7pt) — cm_dominant 必须把"正文字体的小字号字符"也算数学。

14c. **栏边界用众数, 不用分位数**: 首页标题/作者等宽行会把分位数栏左界拉到 x=115,
    导致整页排版框错位、作者行折行与单位行相撞。顶格 x0 的众数才是真栏边界。
    跨栏宽块 (标题/作者, 块宽 > 1.3 栏宽) 的排版框用块自身范围。

14d. **段首缩进拆分会移动 slot id**: 按缩进拆分段落让译文按真实段落对位, 但拆分点之后
    的 id 会顺移 — **翻译键必须在最终 worksheet 上重新对位**, 否则图注/段落错位。

14e. **全宽图注被按栏拆成两个槽** (图注尾部中心x落在另一栏): 尾部槽置空,
    全文并入主槽, 用 \n 分段缩进续行。表格题尾 ('分别以粗体和下划线字体标出。') 同理。

14f. **正文行内公式的上标可能被拆成独立行** (如 'true'): 该碎片槽置空 (抹白),
    记号并入主槽译文的上标标记。

14g. **行距梯子穷尽后缩字号**: (1.50→1.30) x1.0, 再 (1.34/1.30) x0.95, 再 1.30 x0.90。
    参考版工艺自己也缩字 (ATCTrack 参考版有 9.5/9.96), 忠实译文比原文略长属正常。
    单行标题的 fit 公式 (size*1.15) 偏保守, 触发缩排无害。

15. **锚点基线**: 英文行 bbox 顶 y0 对应的基线约在 y0 + 0.80×字号。
    中文首行基线用同一偏移, 段起点即镜像对准。

16. **行距自适应梯子**: 1.50 → 1.30 逐级试, 都装不下再缩字号到 9.5。
    参考版工艺本身也只保证段落起点 ±2pt, 不追求行行对齐。

## 审核坑

17. **像素差分参数**: 灰度差 > 70 + BoxBlur(2) + 28px 网格 + 10% 占比。
    聚类半径 (100, 60)。换分辨率要重调。差分只负责"定位", 定性必须人眼。

18. **对照条假象**: 上下两条裁剪自不同 y, 微小错位看起来像"重影"——先怀疑假象,
    用大图重裁再定性 (本 skill 的 ATCTrack 审核里就有过这种误判)。

19. **has_glyph 骗人**: 子集字体 cmap 缺失时 text_length 仍返回正常值。
    字体是否真画得对, 唯一可靠的是渲染后肉眼看测试卡。

## 图表标签汉化 (overlay v2) 坑

25. **先分清矢量文字 vs 位图烘焙文字**: 数字图 (teaser/framework 图) 的标签若 get_text
    提取不到, 就是整图位图 (标签烘焙在像素里), **汉化不了** — 不要先承诺。表格和
    绘图型插图 (boxes/arrows) 的标签是矢量文字, 可以汉化。
26. **底色采样用环形 8 点取众数**: 上下 ±1.5pt 会采到盒子黑边框 (产出黑条盖字)。
    上下 ±min(2.5, 0.4h) x (-3,0,3) + 左右 ±2, 量化 /8 后取众数。仍不对的标签用
    overlay 的 'bg' 显式指定。
27. **图例行首的图形符号要保护**: 'Ps : Position embeddings' 这类行, 符号 (P_t 圆标)
    和文字在同一行 — 只抹"含 ≥2 个字母的 span", 符号 span 保留; CN 用 align=left
    画在文字 span 起点。
28. **同页多表同名表头 ('Method' ×3)**: overlay 用 'y' 字段 (行中心 y) 消歧,
    匹配最近的行。
29. **匹配用去空格精确相等**, 不用子串 — 否则 'Template' 会命中 'Template tokens'。
30. **表格表头常被上下标行拆散** ('Params'/'(M)' 两行) — 只 overlay 文字行,
    单位行 (M)/(G)/(fps) 保留即可。
31. **整页结果图 (多面板曲线/散点) 的区域检测会失败**: 曲线是稀疏矢量不聚成区域,
    图内 4-5pt 的标签会变成几百个碎片槽。处理: keep_ranges 整页保留 (图注在 keep
    边界之下, 单独作为槽翻译); 同一论文的同类结果图保持同一策略以统一风格。
32. **keep_ranges 必须支持 x 范围**: 参考文献常与正文同页异栏 (右栏参考文献、左栏
    附录正文) — 只给 y 区间会把正文也保留掉。条目支持 {'page','y0','y1','x0','x1'}。
33. **槽位锚点咬合 → 游标顺接 (结构性防叠印)**: 英文行被行内粗体引导词/行内公式切成
    多个槽时, 下一槽锚点可能落在上一槽需要的高度内。引擎按栏维护中文流游标, 锚点被
    咬住时从游标续排 — 比事后修补可靠, 且顺接事件会在构建日志中打印。
34. **overlay 白化要延伸到行尾**: 只抹"含字母的 span"会漏掉行尾的数学加粗记号
    (如 'Expert 𝟏' 的 𝟏), 留下残影叠字。规则: 从首个"字母≥2"的 span 一直抹到行尾。
35. **同 y 多行的 overlay** (同排几个框里都写 'Routed'): 加 'all': True 翻译所有匹配;
    不同 y 的用 'y' 消歧。
36. **保留表格里的设置行也要汉化**: keep_ranges 保住表格结构后, 'model variants' /
    'w/o ...' / 'Conventional MoE' 这类行标签仍应用 overlay 汉化, 与已汉化的表头
    保持一致 (行标签是文字行, overlay 不受 keep 影响)。
37. **语义颜色要复刻**: 原版正文里的彩色 span 有语义 — 链接蓝 (hyperref 的
    citecolor, 如 #367dbd) 覆盖引用编号里的数字/交叉引用 (A.1)/URL; 表注里的
    '红色'/'蓝色' 两词是 #ff0000/#0000ff。中文重画默认全黑会丢掉这些语义。
    做法: content['text_colors'] 用正则+色值列表 (引用 r'\[\s*\d[\d,\s-]*\]'、
    URL、A\.\d+、(?<=[表图]\s)\d+、红色/蓝色), 引擎逐字符染色 (parse_markup 标注,
    draw_line 优先用字符自带颜色)。
38. **可点击链接层 (linkify)**: 克隆页不携带链接注释。左半: 读原页 get_links() 按数据
    重建 (URI 原样, GOTO 页码 1:1 对应); 右半: 扫自己画的中文 rawdict, 引用/URL 建
    LINK_GOTO / LINK_URI。引用目标要用 **倒序页搜索** '[n]' (参考文献在文末, 正序会
    命中正文残片)。

## 模式B 换新论文时新踩的坑 (Springer 单栏排版 / LaTeX 正文用 CM 家族)

39. **正文本身就是 Computer Modern 家族时, "CM 前缀=数学字体" 会把每个正文行都判成数学行**
    (Springer sn-jnl 正文即 CMR10)。短行 + 列内近居中 -> 被误判为独立公式而"保留",
    正文大面积漏翻、keep 计数虚高 (p2 keep 68/76 就是信号)。做法: 由论文实测出正文字体族,
    用 `solo_worksheet.py --math-exclude CMR,CMBX,CMTI,CMSS,CMTT,SF` (构建侧读
    content['math_exclude_stems']) 排除。判断正文字体族的办法: 全页 span 字体按字符数取众数。

40. **只有几条横线的书板表格 (booktabs) 自动检测不到**: 每条规则线是独立 cluster,
    面积远小于区域的 15000 阈值, 聚不成区域。改用 **图注/表注锚定法** (本次做法):
    - 表注在表**上方** -> 区域 = [表注末行底, 下一段正文顶]
    - 图注在图**下方** -> 区域 = [上一段正文底, 图注首行顶]
    - x 外延 = 该带内"实体绘图(高度>3)+光栅图"的外延; 表格另取"带内横线"的外延
      (整页宽表格的横线 x0..x1 才是真宽度)
    - 再把带内"非正文文本行"并入 x 外延: **坐标轴刻度/轴标题是文字不是绘图**,
      只按绘图算会漏掉它们, 刻度数字会变成待翻译槽位

41. **图注/表注行必须挡在保留区之外** (它们要翻译), 且要连**续行**一起挡:
    续行判据 = 与首行同 x0 (±3pt) 且行距 ≤5.5pt。少了这一步, 表注第二行会被保留成英文。
    另注意: 正文里以 "Table 2 and in the AR plot..." 开头的句子会被 `^(Fig\.|Table)\s*\d`
    误判成表注 -> 图注判据必须再加"字号 < 正文字号"。

42. **栏归属按"行左缘"判定, 不能按行中心**: 整宽块 (摘要、跨栏图注) 按中心会被劈成左右两栏,
    图注被拆成互不相连的三个槽; 按左缘则整块归左栏, 排版框 (块宽 > 1.3 栏宽时用块自身范围)
    自然横跨整宽。

43. **栏边界 (col_edges) 的众数会被整宽块污染**: 摘要 x0=90.8 行数最多 -> 被当成栏左界,
    整栏排版框变成 [91,497] 横跨中缝, 中文压到另一栏上。修法: 只统计**完全落在本栏内**
    (x0 ≥ 栏左-3 且 x1 ≤ 栏右+3) 的行再取众数。

44. **同一视觉行被 dict 拆成多个 line 对象**: 粗体 "Fig. 1" + 图注正文; 分数的分子 "1" + 分母。
    不合并就会出现 "Fig. 1" 单独成槽、字号变化规则误判成分段。判据: `|Δy0| < 0.6×字号`
    即同一视觉行 (上标脚注标记抬高 3pt 也在此范围内; 而 12pt 行距的相邻行差 12pt 不会被误并)。

45. **项目符号的悬挂缩进不是新段**: 缩进行之后**仍然缩进** -> 列表。缩进拆段要往后看一行:
    下一行与当前行 x0 相同则不拆。

46. **页码 (folio)** 排在版面底部栏缝正中 (Springer), 既不抹白也不翻译 —— 否则会凭空多出一个
    "1" 的槽位, 抹掉后右页连页码都没了。

## overlay / 链接 / 排版 新坑

47. **overlay 底色采样必须采"源页"**: 输出文档在 `save()` 之前 `get_pixmap()` 渲染为**空白**
    (PyMuPDF 行为), 采输出页只会得到纯白 -> 彩色底 (如黄色框) 上会盖出白块。
    右半是 1:1 克隆, 直接采源页同一坐标即可。

48. **同页多行同名标签**: 两个面板都有 "Frame t" / "FIXED" -> 必须 `'all': True`,
    否则只换第一处 (审核时会看到一处中文一处英文)。图内标签与表头同名 (图 5 轴标题
    "Accuracy" vs 表 2 表头 "Accuracy") 用 `'y'` 消歧。

49. **LINK_NAMED (kind=4) 也要重建**: LaTeX hyperref 的跳转几乎全是 kind=4 (具名目标),
    只处理 LINK_GOTO/URI 会把 478 个引用跳转全丢掉 (本次 7 vs 481)。

50. **旋转的轴标题**: `insert_textbox(rotate=90)` 仍然沿**矩形宽度**排版 (竖标签的可用宽度
    只有 7pt, 必然塞不下, 返回负值静默失败)。改为逐字 `insert_text(point, ch, rotate=90)`
    沿 y 自下而上叠排。

51. **中文避头尾**: 逐字断行会让 `，。、；：？！）` 落在行首。wrap 里遇到"该字是禁则符号 &&
    单字一行"时, 把它挂到上一行末尾 (允许轻微出界), 观感立刻正常。

52. **蓝色引用/链接色**: 用 `[[...]]` 标记 (content['cite_color'] 给色值), 引擎逐字符染色。
    **未闭合的 `[[` 会原样渲染出方括号且丢色** —— 交付前必须跑标记配对校验
    (`[[ ]]`/`**`/`$`/`^{}`/`_{}` 计数 + 反斜杠扫描)。跨槽位的引用要在两个槽里各自闭合。

53. **译文里不得残留 LaTeX 命令**: `$rac{a}{b}$` 这种写进 cn 字段会原样画出 "rac"。
    分数用 "½" 之类的字符, 或拆成 `^{1}/_{2}` 形式。

## 模式B 批量生产七篇的新坑 (54–62)

54. **is_folio 必须加"短标"条件**: 页码判据原为"行中心距页心<12pt 且 y0>0.8H"。单栏论文的
   整宽正文行中心正好是页心 → 页面底部约 20% 的正文行全被当页码，**既不抹白也不翻译**，
   右半留整段英文（单栏一篇可漏翻 150 行）。修法: 加 `(ln['x1']-ln['x0']) < 0.15*W`。
   残余风险: 双栏论文右栏起点=页心，栏内**段末短行**（如 'can.'/'itself.'）中心也落进 ±12pt
   → 仍会被当页码保留；用 overlay 显式框（55）抹白兜底。勿再加"纯数字"条件收紧——会误伤
   图轴刻度数字（它们本就该随图保留）。旧绕法"派生源 MediaBox 下延+交付前裁回"在引擎
   修复后不再需要。
55. **overlay 显式抹白框**: ov 带 `x0/y0/x1/y1` 时按该框整行抹白（源页坐标）。场景: 公式碎片
   以 `(` 或单字母开头，默认的"首个字母≥2 的 span 到行尾"规则会留残字 `"(M"`；或 folio 误判
   行的精确清除。`cn: ''` = 只抹白不写字。
56. **槽位显式排版框 box**: 栏右界取"行右端众数"，参考文献页的窄条目会把众数拉偏 → 页眉槽
   变窄折行。content 槽加 `box:[x0,x1]` 与栏宽解耦（页眉/整宽块适用）。
57. **overlay 匹配池必须用未过滤行**: folio 行不在 lines 里，overlay 匹配不到 → 匹配池改用
   `get_lines(page)` 全量。overlay 是显式指令，不应被分类过滤挡住。
58. **译文引号词之间必须留空格**: wrap 把"连续西文+引号"当**不可断长词**（仅空格/CJK 处可断），
   `“animal”“gorilla”…` 缺空格 → 83 字符长词溢出栏宽压到邻栏。**门禁盲区**: 叠印检查只比较
   排序后**相邻**框，跨栏溢出对会漏检 → 用"分词宽度 vs 栏宽"扫描器排查（复刻 wrap 分词 +
   字体实测字宽）。
59. **参考文献标题要单独翻译**: 参考文献条目保留英文，但 `References` 标题应译作「参考文献」
   （全批一致）。标题常落在保留区内 → 用 overlay 处理。
60. **重建后必须立即重渲审核图**: judge/人眼读到旧渲染图会误判（修复明明生效却报 fail）。
   `_audit/mine_pN.png` 的 mtime 必须晚于 PDF 的 mtime；派发 judge 前先重渲。
61. **构建日志必须 `> build.log 2>&1`**: `2>` 只捕 stderr 得到空文件，门禁"日志无警告"形同
   虚设（本批一篇的 2 个真实行距警告被空日志掩盖，靠人眼复检才暴露）。
62. **期刊 running header 是逐页槽位**: TMLR/LNCS 等的页眉文字行每页重复，逐页翻译（页码
   数字槽 cn 原样填数字）。注意 header 槽的排版框可能被该页栏边界众数拉偏（见 56）。

## 第二批七篇实战新坑 (63–74)

63. **content 槽 id 不在重建 worksheet 时引擎静默回退**：被 zone/trim 重分类后部分槽 id 会顺移，
    引擎对 content 中不存在的 id 静默改用 content 自带坐标 → 译文整体错位、列游标被顶出页外而
    **无任何告警**。做法：重跑 worksheet 后按 (page, col, en_first) 重新对位译文；**强烈建议
    引擎对"id 不在重建 worksheet"打印显式警告**（本批两个 agent 各自踩到）。
64. **槽序必须按"重建 worksheet 的真实 y0"排**：自定义槽（只给 id/page/col/cn，无几何字段）
    若按 content 自带 y0 排会全部落到 0 而被排到最前 → 列游标顺接把后续槽的中文一路推到栏底
    （本批 KeepTrack p16/p17 的标题就是这样被推到栏底的）。正确做法：`sort(key=lambda s:
    (s['page'], s['col'], ws_y0[s['id']] if s['id'] in ws_y0 else s.get('y0') or 0))`。
65. **自定义槽只需 id/page/col/cn**：引擎会从重建 worksheet 取几何（x0/x1/y0/gap/size）。
    若该 id 不在 worksheet 里，引擎才回退用 content 的（可能缺失）字段。门禁的"合并感知覆盖"
    需跳过无 y0 的自定义槽，否则 KeyError 崩溃（check_release 已加固）。
66. **行内分式的分母/分子碎片行会被 is_equation 误判为独立公式保留**：短行 + CM 斜体 +
    列内近居中三条件恰好满足（本批 MixFormer 8 处、SeqTrack 7 处、OSTrack 27 处）。右半会
    残留英文碎片（有时四栏相交、挂在中文句尾）。做法：逐页排查含行内分式的段落，用 overlay
    显式抹白框（x0/y0/x1/y1 + cn:'' + **保留 find** + bg [1,1,1]）抹掉，语义按 inline 记号
    （如 H_t/4、⌊Wz/2⌋）织进中文。**建议引擎自动识别"与正文行同行邻接的保留行"为碎片**。
67. **假小型大写触发公式误判**：'GRAY .' 这类"首字母全尺寸 + 其余 0.8×"的伪小型大写命中
    cm_dominant 的 sub-size 规则 → 表注/章节标题被判为公式并被"邻域生长"链式吸收整段。
    建议引擎把"非 CM 字体的 sub-size 字符"从 cm_dominant 摘除，或提供字体白名单参数。
68. **数学标记严禁嵌套**：`^{...}` 的内容里再写 `_{...}`/`^{...}` 不会被解析（TOKEN 正则在
    首个 `}` 截断），内层花括号与下划线会**原样画出**（本批 STARK/ViT/TransT 三篇各自踩到）。
    多层上下标用 Unicode 拍平（ˢ ₕ 等），或改写公式结构。写完 cn 必须自查正则
    `[\^_]\{[^{}]*\{` 零命中。
69. **overlay 显式抹白框不决定纵向位置**：纵向仍用被匹配行的 oy；同一标签在多处出现时若不传
    未文档化的 `y` 字段，所有副本的中文都会画在第一处匹配的 y 上（并触发门禁叠印）。
70. **源 PDF 同一标签被重复绘制**（图内标签画两遍）：`all:True` 会把中文也画两遍 → 门禁
    "中文叠印"假阳性（构建期碰撞检测看不见）。改用按位置区分的显式框。
71. **白框 overlay 必须保留 `find` 字段**：门禁第 4 项（中文×保留英文）用 overlays 的 find
    集合做豁免，缺 find 会让白框位置被判成冲突。
72. **keep_ranges 覆盖的空槽仍触发构建 `[警告] 未填写`** → 日志过不了门禁第 7 项。做法：从
    content 删除这些槽（门禁第 2 项按 kept_by_range 判定通过）。建议引擎对 keep 覆盖的空槽免警告。
73. **zone_trim 是页级的**（作用于该页全部 zone），无法分栏手术 → 分栏问题用 extra_zones 打补丁。
74. **审核纪律（本批固化）**：
    - 重建后**立即重渲 `_audit/mine_pN.png`**，judge 会核对 mtime 晚于 PDF；
    - judge 在渲染分辨率下的**字级疑点**（数字/词）要用**文本层 + 源文**复核：本批 4 例中
      3 例是误读（80GB→8GB、"3 层"→"7 层"、确切→确实），1 例是真错（八个基准译成"四个"）；
    - 有底色图元上的标签替换必须**实测底色**后显式给 `bg`，别靠环形采样（本批 ViT p3 黑块
      事故即采样采到描边）；
    - 单栏论文页底整宽行、双栏论文右栏段末短行是 folio 误判的两个高发位置。

75. **skill 版与仓库版的字体块必须各自保留，只同步业务改动**：两份 `build_solo.py` 的字体解析
    块**本来就是不同的**——skill 版走 Windows 字体路径（`WINDIR/Fonts` 下的 times.ttf 等）+ `<skill>/_fonts/`，
    仓库版走跨平台 `fontconfig.py`（Linux 找 Liberation/DejaVu、macOS 找系统 Times）+ `<repo>/fonts/`。
    `setup_fonts.py` 同理（skill 下载字体，仓库从系统解析）。
    **严禁把一份整体复制覆盖另一份**——曾把 skill 版覆盖到仓库，导致 CI 在 ubuntu 上
    `SystemExit: 字体缺失 ['NSR','NSB','CMI','SYM','TMR',...]`（提交 2e20927 引入、c4edc87 回滚）。
    正确做法：用 Edit/补丁**只把业务改动点**打进两个文件，改完 `diff` 复核差异只落在字体块，
    并逐项 grep 业务标记（如 `_slot_key` / 告警文案）确认两边命中数一致。
    另：`diff` 显示这两处差异是**预期的**，不是漏同步。

76. **改引擎后必须验证"行为中性"**：任何 build_solo/门禁改动，都要用一份已有 content 重建并
    与已交付 PDF 做**逐页像素对比**（`get_pixmap` + `ImageChops.difference`），确认零差异才推。
    本批用此法验证了 STARK/SAM2/OSTrack 共 77 页零差异。仓库侧改动还要**先本地跑通 CI 的四步**
    （`mkzones → build_solo → links_ay → check_release`）再 push——CI 跑在 ubuntu + Python 3.12，
    本机 Windows 通过不代表 CI 通过（字体解析差异就是靠这一步才暴露的）。
