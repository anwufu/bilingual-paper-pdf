# 审核协议（任何视觉模型/人工都可执行）

机器自检（`check_release.py`）负责**定位**，本协议负责**定性**。两遍审核是交付门槛，
审核不过不得交付。

## 第 0 遍：机器验收门

```bash
python scripts/check_release.py --src 原文.pdf --content content.json \
    --pdf 成品.pdf --build-log build.log
```

7 项全过才进入人工/视觉审核。失败项先修后审。

## 第一遍：逐页全检

1. 渲染：成品每个跨页导出 PNG（约 100dpi）。
2. 逐页检查清单（右半 = 中文页）：
   - 每段中文起点是否贴着左页对应英文段起点（±2pt 工艺精度）
   - 无英文正文残留（图表内/方法名/参考文献保留英文属正常）
   - 无叠印、无溢出、无跨中缝
   - 无豆腐块、无错字（对照 fonts_test.pdf）
   - 图/表/公式完整无损；图内标签与表头已汉化
   - 引用为蓝色；左右页版式气质一致（字号/行距/缩进/对齐）
3. 记录每个疑点的**页码 + 位置坐标 + 现象**。

## 第二遍：差异定性

对第一遍收集的每个疑点，放大裁剪（4–6 倍）逐一判定：

- **内容级差异**（必改）：错译、漏译、叠印、压线、残留英文正文、颜色丢失、
  链接缺失、字形错误。
- **渲染级漂移**（可接受）：亚像素错位、抗锯齿灰度差、连字替换、跨平台字形微差。

判定纪律：每个 fail 必须能指出具体坐标；判"可接受"必须能说明为什么不影响读者。
上下两条裁剪自不同 y 的对照图会有重影假象——先怀疑假象，用大图重裁再定性
（pitfalls 18）。

## 修复循环

发现问题 → 修 content.json / zones / 构建参数 → **重新构建 → 重跑第 0 遍 → 重跑
两遍审核**。修 A 破坏 B 是常态，全量重审不可省。

## 参考：典型误报

- 右页与源页文字行数一致 ≠ 漏抹白：克隆的英文在 PDF 内部仍存在，被白色矩形覆盖，
  提取器看得到、读者看不到。只把**保留区**英文当作可见冲突对象。
- 行 bbox 相交 ≠ 视觉叠印：NotoSerif 行框含字体级上升部（约 0.24em 虚高），
  比较墨迹框（上剪 0.24em、下剪 0.05em）再判。
